# SimScale project page

## Layout

| File | Purpose |
| --- | --- |
| `index.html`, `styles.css` | Page content and styles |
| `script.js` | Hero, comparison and demo tabs, lazy posters, video autoplay, reveal on scroll |
| `outline.js` | Contents menu |
| `rollouts.js`, `research-details.js` | Rollout video players and the category video tabs |
| `method.js` | Animated method overview and AssetEngine intro |
| `figures.js` | Bar charts rebuilt from the paper figures |
| `generator-playground.js`, `generator-worker.js` | Interactive AssetEngine generators |
| `media/` | Videos, images, and the generator bundle |
| `vendor/` | Three.js 0.169.0 (MIT) and manifold 3.5.3 (Apache-2.0), with licenses |
