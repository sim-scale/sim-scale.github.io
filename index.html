Where SimScale extends prior work

Articraft & asset generation

Articraft uses agents to author individual articulated assets. SimScale uses its SDK to author reusable category-level generators, then samples controlled variation and connects it to robot data generation.

Articraft paper ↗

RoboCasa & SimFoundry

Curated asset libraries and real-to-sim twins or cousins provide alternative training geometries. SimScale learns from a sampled category distribution; our simulation study compares these sources with the same demonstration budget.

View the measured comparison ↑

DexMimicGen

DexMimicGen efficiently expands source demonstrations across poses. SimScale adds agent-authored task programs and geometry-specific source adaptation, then uses DexMimicGen for pose expansion.

DexMimicGen project ↗

MolmoBot

MolmoBot scales task-and-motion-planning data for pick-and-place and articulated-object tasks. SimScale studies geometry-aware source generation for bimanual pot placement, mug hanging, and charger placement. These are different task suites, with no head-to-head score reported here.

Inside the engines
01

AssetEngine

Build a category, not one object.

AssetEngine writes one parameterized procedural generator whose controls describe meaningful variation across an object category.

  1. SearchCollect diverse real-world examples and identify task-relevant variation.
  2. AuthorEncode dimensions, part choices, dependencies, joints, and semantic metadata.
  3. ReviewA coverage critic checks the category range; a geometry validator checks simulation readiness.
  4. SampleCompile accepted parameter settings and split assets into training and held-out sets.

OutputDiverse, physically plausible simulation assets

→Assets + metadata
02

DemoEngine

Adapt the skill across geometry and pose.

DemoEngine turns the reference trajectory into a reusable task program, then uses simulation feedback and robot tools to make it work across the asset family.

  1. DecomposeRead the demonstration as semantic stages such as grasp, handover, insert, and retreat.
  2. ProgramCompose motion planning, gripper control, collision checking, and object-centric targets.
  3. SpecializeRevise targets or task logic for each geometry and retain only successful executions.
  4. ExpandUse DexMimicGen to transform accepted trajectories across sampled object poses.

OutputDiverse, successful demonstrations across assets and poses
